# Video Converter

Статус: `tested`  
Зрелость: `M3`  
Версия: `0.3.0`  
Флаги: `D, P`  
Основной интерфейс: `cli`

## Что делает

Безопасная CLI-обёртка для пакетной конвертации `.mkv` в `.mp4` через `ffmpeg`. Это переработка исходного однофайлового скрипта: личный абсолютный путь удалён, удаление оригиналов выключено по умолчанию.

## Когда использовать

Когда в папке лежат `.mkv` файлы и нужно получить `.mp4` копии с понятным отчётом. Для медиаархивов сначала запускайте `--dry-run`.

## Быстрый запуск

Windows:

```powershell
run.bat "D:\Видео" --dry-run
run.bat "D:\Видео" --report report.json
```

Linux:

```bash
sh run.sh ./video --dry-run
sh run.sh ./video --report report.json
```

Лаунчеры не меняют текущую папку: их можно вызывать по полному пути из папки с видео, относительные пути в аргументах считаются от папки запуска.

Напрямую:

```bash
python src/cli.py ./video --dry-run
python src/cli.py ./video --output-dir ./converted --report report.json
```

## Вход

Папка с `.mkv` файлами. По умолчанию обрабатываются только файлы верхнего уровня. Для вложенных папок используйте `--recursive`.

## Выход

`.mp4` файлы рядом с исходниками или в папке `--output-dir` (структура вложенных папок сохраняется). JSON-отчёт создаётся через `--report`.

Итоговая сводка в stdout: сколько файлов найдено, создано, пропущено, удалено, сколько ошибок, где результат и где отчёт. В dry-run дополнительно — сколько файлов запланировано.

Во время конвертации рядом с результатом лежит временный файл `имя.vc-partial.mp4`; он становится `имя.mp4` только после успеха, а после ошибки удаляется.

Коды возврата: `0` — без ошибок, `1` — часть файлов с ошибкой, `2` — запуск невозможен (нет папки, нет ffmpeg, неверные аргументы).

## Побочные эффекты и предупреждения

- Удаляет файлы: только при явном `--delete-originals`, и только тот оригинал, для которого ffmpeg завершился успешно и выходной файл существует и не пуст. При ошибке, при пропуске и в dry-run оригинал остаётся.
- Перезаписывает файлы: только при явном `--overwrite`. Без него существующий `.mp4` пропускается. Файл отчёта `--report` заменяется всегда.
- Backup не создаётся: перезаписанный `.mp4` и удалённый `.mkv` инструмент восстановить не может.
- Использует сеть: нет.
- Запускает внешние команды: да, запускает `ffmpeg` как внешнюю программу.
- Может содержать приватные данные: да. JSON-отчёт и вывод в консоль содержат абсолютные пути и имена медиафайлов; при ошибке в отчёт попадает последняя строка сообщения ffmpeg. Содержимое файлов и полный вывод ffmpeg не сохраняются, других логов инструмент не ведёт.

Флаг `D` стоит из-за опционального удаления оригиналов и перезаписи. Флаг `P` — из-за путей к медиафайлам в отчёте. С `--delete-originals` указывайте и `--report`, иначе список удалённого останется только в консоли (инструмент об этом предупредит).

## Проверка

```bash
python scripts/smoke_test.py
```

Тест запускается из любой папки, пишет только во временную папку, не использует сеть и не требует ffmpeg. Последняя строка при успехе: `video_converter smoke passed`.

Что проверяется автоматически:

- dry-run и JSON-отчёт на `examples/input` — сравнение с эталонами в `examples/output_expected`; dry-run с `--delete-originals` и `--overwrite` ничего не меняет;
- на копии примеров с заглушкой ffmpeg (скрипт во временной папке): существующий `.mp4` не перезаписывается без `--overwrite`; оригиналы удаляются только после успеха; при сбое ffmpeg оригинал и прежний `.mp4` целы и не остаётся временных файлов; `--output-dir` сохраняет структуру папок;
- сообщения и коды возврата, когда нет ffmpeg, нет папки или папка пуста;
- запуск через `run.sh` с относительными путями из другой папки;
- если установлен ffmpeg с `libx264` и `aac`: настоящая конвертация односекундного синтетического ролика (при наличии ffprobe — проверка кодеков результата). Без ffmpeg этот шаг пропускается с сообщением, остальное проверяется.

Что не проверяется:

- Windows и `run.bat` — статус `expected`, на Windows никто не запускал;
- большие и настоящие пользовательские файлы, длительная конвертация, качество результата;
- имена файлов не в UTF-8 и нехватка места на диске;
- если временная папка не разрешает запуск файлов, проверки на заглушке пропускаются, и тест прямо об этом пишет.

Проверено на Linux с Python 3.11 и 3.13, ffmpeg 6.1.

Примеры и эталоны описаны в [examples/README.md](examples/README.md).

## Как изменить под себя

- CLI-аргументы и логика: `src/cli.py`.
- Формат отчёта: функция `write_report`. Меняете поля — обновите `docs/CONTRACT.md` и эталоны (`python scripts/smoke_test.py --update-expected`).
- Команда ffmpeg: функция `build_ffmpeg_command`.

## Граница применимости

Инструмент не редактирует видео и не подбирает оптимальные параметры качества. Он запускает стандартную перекодировку `libx264 + aac`. Для архивных оригиналов используйте output-only режим и не включайте `--delete-originals` без backup.
