# История изменений devctl_universal

Здесь ведётся история капсулы на полке. История самого devctl ведётся в его собственном репозитории.

## 0.6.7-cli-0.2.2-gui — оформление M3

Код `devctl.py` и GUI не менялся; версия прежняя.

- Smoke-тест стал сквозным: во временном workspace с настоящим Git проверяются `plan`, успешный `start --no-push`, упавшая проверка с автоматическим откатом, отказ на небезопасном пути, `reset`, `status --json`. Раньше проверялись только `--version` и наличие файлов.
- Добавлены `docs/CONTRACT.md` (версия контракта 1 = `formatVersion: 1` манифеста патча) и этот файл.
- `run.sh` и `run.bat` больше не переходят в папку капсулы: workspace ищется от папки, из которой запущена команда, как при прямом вызове `devctl.py`. Раньше `run.sh status` искал workspace от папки капсулы.
- В README записано, что копия на полке отстаёт от devctl в его собственном репозитории.

## 0.6.7-cli-0.2.2-gui — зрелость M3 (исходное состояние)

- CLI `devctl.py` 0.6.7: `init`, `sync`, `status`, `inspect`, `plan`, `start`, `reset`, `completion`, `self`.
- Tkinter GUI 0.2.2 — оболочка над тем же `devctl.py`.
- Документы: пример манифеста, пример конфигурации workspace, установка CLI, шаблон prompt-а для патчей, сборка Windows EXE.
