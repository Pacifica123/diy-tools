# История изменений Markdown Splitter

## 0.3.0 — зрелость M3

Добавлено:

- `docs/CONTRACT.md` — внешний контракт версии 1; поле `"contract_version": 1` в `index.json` и в выводе `--json` (прежнее поле `formatVersion` сохранено).
- Регрессионные примеры `examples/input/` и эталоны `examples/output_expected/`. Прежний `examples/sample.md` переехал в `examples/input/sample.md`.
- `scripts/smoke_test.py` переписан: сравнение с эталоном, инварианты нарезки, CRLF+BOM, `--dry-run`, защита от перезаписи, ошибки входа, запуск через `run.sh`.
- Итоговая сводка после работы: `Готово.` / `Обработано` / `Создано` / `Предупреждений` / `Ошибок` / `Результат` / `Отчёт`.
- Справка `--help` полностью на русском, с кодами возврата.

Исправлены ошибки, найденные при подготовке регрессионных примеров:

- документ без заголовков: в частях-продолжениях синтетический `# <имя файла>` вставлялся дважды; с YAML front matter он дублировался уже в первой части;
- заголовок, за которым идёт неделимый блок больше лимита, уходил в отдельную часть из одного заголовка; теперь заголовок остаётся вместе со своим блоком;
- если в лимит не помещались только пустые строки перед новой секцией, следующая часть начиналась с лишнего повтора предыдущего заголовка, а в конце документа создавалась часть из одного повторённого заголовка;
- заголовок секции мог остаться последней строкой части, а её текст — уйти в следующую; теперь такой заголовок переносится в следующую часть вместе с текстом, если помещается в лимит;
- размер части считался до добавления завершающего перевода строки: файл без перевода строки в конце мог превысить лимит на 1 байт без предупреждения;
- `--output-dir`, указывающий на существующий файл, и ошибки чтения/записи давали traceback вместо сообщения `Ошибка: …` и кода 1.

Изменения поведения, заметные пользователю:

- часть называется по своему первому заголовку, а не по последнему (меняются имена файлов и `title` в `index.json`);
- текстовый вывод без `--json` заканчивается сводкой вместо строк «Создано частей» / «Папка»;
- `run.sh` и `run.bat` больше не переходят в папку капсулы: относительные пути считаются от текущей папки пользователя. Раньше относительный путь, переданный запускалке, искался внутри капсулы.

Проверено автоматически только на Linux; Windows — `expected`.

## 0.2.0 — зрелость M2

Состояние до 0.3.0:

- CLI режет UTF-8 Markdown по границам блоков: не разрывает fenced code blocks, таблицы, blockquote и пункты списков, распознаёт ATX- и Setext-заголовки.
- Повтор ближайшего заголовка в частях-продолжениях, синтетический заголовок для текста до первого заголовка.
- Мягкий лимит `--max-size`: неделимый блок больше лимита сохраняется целиком с пометкой `oversized`.
- Запись в новую папку, отказ писать в непустую `--output-dir`, `--dry-run`, `--json`, `index.json` с `formatVersion = 1`.
- Smoke-тест на одном встроенном примере, без эталонных выходов.

Эта версия заменила исходный однофайловый скрипт, который закрывал часть посреди абзаца, списка или блока кода.
