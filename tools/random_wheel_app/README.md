# Random Wheel App

Статус: `tested`  
Зрелость: `M3`  
Флаги: `I`  
Основной интерфейс: `gui`

## Что делает

Десктопное колесо случайного выбора на Python/PySide6. Инструмент импортирует TXT-список вариантов, крутит колесо в равном или взвешенном режиме, сохраняет историю и экспортирует результат.

## Когда использовать

Когда нужно выбрать один вариант из списка, но при этом сохранить историю, seed и объяснимые правила выбора. Подходит для личных списков задач, игр, челленджей, бытового рандома.

## Быстрый запуск

Windows:

```powershell
run.bat
```

Linux:

```bash
sh run.sh
```

Напрямую:

```bash
python main.py
```

Перед первым GUI-запуском:

```bash
python -m pip install -r requirements.txt
```

Если PySide6 не установлена, запуск не падает с traceback, а печатает сообщение с командой установки (в Arch Linux пакет ставится через `pacman -S pyside6`).

## Вход

TXT-файл, где каждая непустая строка имеет один из форматов:

```text
вариант
вариант : вес
```

Примеры лежат в `examples/input/`: `sample_equal.txt`, `sample_weighted.txt` и `список с ошибками.txt` (все особые случаи разбора). Подробности: `docs/input_format.md`.

## Выход

GUI показывает выпавший вариант, текущие сегменты и историю. Историю можно экспортировать в TXT, CSV или JSON; после экспорта окно показывает итог: «Готово. / Экспортировано записей: N / Результат: путь».

Autosave хранит состояние сессии в одном файле в домашнем каталоге пользователя: `~/.random_wheel_app_autosave.json` (в Windows — `C:\Users\<имя>\.random_wheel_app_autosave.json`). Он записывается при открытии колеса и после каждого вращения; кнопка «Продолжить autosave» возвращает сессию с того места, где она остановилась. Внутрь папки инструмента ничего не пишется.

Отдельной отмены вращения (undo) нет: выпавший вариант возвращает на колесо кнопка «Вернуть все варианты», записи убирает «Очистить историю».

При seed, отличном от 0, результат воспроизводим: тот же список, режим и seed дают ту же последовательность выпавших вариантов. Правило выбора описано в `docs/CONTRACT.md`.

## Побочные эффекты и предупреждения

- Удаляет файлы: нет.
- Перезаписывает файлы: файл экспорта — по выбору пользователя; autosave один на пользователя, и открытие нового колеса перезаписывает прежнюю сессию без вопроса.
- Использует сеть: нет.
- Запускает внешние команды: нет.
- Может содержать приватные данные: да, если пользователь сам занёс приватные варианты в список или экспорт.

## Проверка

```bash
python scripts/smoke_test.py
```

Тест запускается из любого каталога, требует только стандартную библиотеку Python и пишет только во временный каталог (ни в папку инструмента, ни в пользовательский autosave). Он прогоняет настоящие `app/domain` и `app/storage` на файлах из `examples/input/` и сравнивает результат с эталонами в `examples/output_expected/`.

Что проверяется:

- разбор TXT: равный и взвешенный примеры, файл со всеми «плохими» строками, кириллица, UTF-8 с BOM, Windows-1251, CRLF, путь с пробелами;
- сегменты колеса и точная последовательность выпавших вариантов при заданном seed (равный и взвешенный режим, режим «удалять выпавший вариант»);
- короткая сессия: вращения → autosave → загрузка → состояние совпадает → продолжение даёт ту же последовательность, что непрерывная сессия; очистка истории;
- экспорт истории в TXT, CSV и JSON — сравнение с эталонными файлами;
- загрузка записанных файлов сохранения (текущий формат и формат версии 0.1.0), а также повреждённых, чужих и более новых файлов: только понятная русская ошибка, файл не изменяется;
- запуск `main.py` без PySide6 даёт сообщение с командой установки и код 1.

Что НЕ проверяется:

- GUI-слой (`app/ui`, PySide6): окна, анимация, диалоги не запускались — у файлов проверен только синтаксис. Окно проверяется вручную: запустить, импортировать `examples/input/sample_weighted.txt`, сделать вращение, закрыть, «Продолжить autosave», экспортировать историю;
- Windows: статус `expected`, никто не запускал;
- `run.sh` / `run.bat` автоматически не запускаются.

Проверено на Linux с Python 3.11, 3.12 и 3.13: последовательности при seed совпадают на всех трёх.

После осознанного изменения поведения эталоны обновляются командой `python scripts/smoke_test.py --update-expected` (и записью в `CHANGELOG.md`).

## Граница применимости

Колесо делает случайный выбор по заданным правилам, но не оценивает реальную полезность вариантов. Взвешенный режим зависит от корректности чисел во входном файле. Слот autosave один: чтобы сохранить прежнюю сессию, скопируйте файл autosave до открытия нового колеса.
