# Random Wheel App

Статус: `working`  
Зрелость: `M2`  
Флаги: `I`  
Основной интерфейс: `gui`

## Что делает

Десктопное колесо случайного выбора на Python/PySide6. Инструмент импортирует TXT-список вариантов, крутит колесо в равном или взвешенном режиме, сохраняет историю и экспортирует результат.

## Когда использовать

Когда нужно выбрать один вариант из списка, но при этом сохранить историю, seed и объяснимые правила выбора. Подходит для личных списков задач, игр, челленджей, бытового рандома.

## Быстрый запуск

Windows:

```powershell
run.bat
```

Linux:

```bash
sh run.sh
```

Напрямую:

```bash
python main.py
```

Перед первым GUI-запуском:

```bash
python -m pip install -r requirements.txt
```

## Вход

TXT-файл, где каждая непустая строка имеет один из форматов:

```text
вариант
вариант : вес
```

Примеры лежат в `examples/sample_equal.txt` и `examples/sample_weighted.txt`. Подробности: `docs/input_format.md`.

## Выход

GUI показывает выпавший вариант, текущие сегменты и историю. Историю можно экспортировать в TXT, CSV или JSON. Autosave хранит состояние пользовательской сессии.

## Побочные эффекты и предупреждения

- Удаляет файлы: нет.
- Перезаписывает файлы: может перезаписать autosave/export по выбору пользователя.
- Использует сеть: нет.
- Запускает внешние команды: нет.
- Может содержать приватные данные: да, если пользователь сам занёс приватные варианты в список или экспорт.

## Интерфейсы

| Слой | Статус | Комментарий |
|---|---|---|
| core | yes | `app/domain/*` |
| api | internal | доменные функции импортируются smoke-тестом |
| abi | simple_files | TXT input, TXT/CSV/JSON export |
| cli | no | GUI-инструмент; smoke-тест отдельно |
| gui | yes | PySide6 |
| apk | no | телефонный сценарий не заявлен |
| web_localhost | no | не требуется |

## Зависимости

- Python: `>=3.11`
- pip: `PySide6>=6.7`
- external: `none`

## Проверка

```bash
python scripts/smoke_test.py
```

Smoke-тест проверяет parser, равные/взвешенные сегменты, seed и запись одного spin-record без запуска GUI.

## Как изменить под себя

- Доменная логика: `app/domain/`.
- Хранение/autosave: `app/storage/`.
- Окна и виджеты: `app/ui/`.
- Формат входа: `docs/input_format.md`.

## Граница применимости

Колесо делает случайный выбор по заданным правилам, но не оценивает реальную полезность вариантов. Взвешенный режим зависит от корректности чисел во входном файле.
