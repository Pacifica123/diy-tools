# Архитектура проекта

Проект устроен так же, как исходный турнирный прототип: доменная логика отдельно, интерфейс отдельно.

```text
app/domain/models.py       dataclass-модели: вариант, настройки, история, сессия
app/domain/parser.py       импорт TXT-словарика
app/domain/wheel.py        расчёт весов, сегментов и выбор победителя
app/domain/export.py       экспорт истории
app/storage/               autosave и JSON-сессии
app/ui/                    PySide6-интерфейс и отрисовка колеса
```

GUI не выбирает победителя сам. Он вызывает `WheelEngine`, получает выбранный вариант и только затем анимирует колесо так, чтобы выбранный сегмент оказался под указателем.
