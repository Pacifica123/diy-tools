# Формат входного файла

Файл обычный TXT. Одна непустая строка = один вариант для колеса.

Поддерживаются два вида строк:

```text
название варианта
название варианта : значение
```

Пример без значений:

```text
весь день в шахматы (минимум 12 часов чисто игры)
весь день программирование (минимум 12 часов чисто разработки)
```

Пример со значениями:

```text
весь день в шахматы (минимум 12 часов чисто игры) : 10
весь день программирование (минимум 12 часов чисто разработки) : 20
```

В режиме `без значения` все варианты имеют одинаковую площадь сегмента.

В режиме `со значением` площадь сегмента пропорциональна числу. Если у шахмат значение `10`, а у программирования `20`, то сегмент программирования в 2 раза больше, и шанс выпадения в 2 раза выше.

Пустые строки игнорируются. Строки, начинающиеся с `#`, считаются комментариями.

Если после `:` стоит не положительное число, вариант всё равно добавляется, но приложение покажет предупреждение. В режиме со значениями такой вариант получает вес `1`.

## Кодировка

Файл читается как UTF-8 (с BOM или без), при неудаче — как Windows-1251. Переводы строк — любые (LF или CRLF).

## Как разбираются особые строки

Значение ищется после **последнего** двоеточия в строке. Пробелы по краям названия и значения обрезаются. Дробную часть можно писать через точку или запятую.

| Строка | Вариант | Вес | Предупреждение |
|---|---|---|---|
| `вариант` | `вариант` | нет | нет |
| `вариант : 3` | `вариант` | 3 | нет |
| `вариант : 2,5` | `вариант` | 2.5 | нет |
| `Ёлка: украшаем дом : 7` | `Ёлка: украшаем дом` | 7 | нет |
| `вариант : 0`, `вариант : -5`, `вариант : inf` | `вариант` | нет | да |
| `вариант :` | `вариант` | нет | да |
| `вариант : много` | `вариант : много` (вся строка) | нет | да |
| `двоеточие в названии: без веса` | `двоеточие в названии: без веса` (вся строка) | нет | да |
| `встреча в 12:30` | `встреча в 12` | 30 | нет |
| ` : 5`, `:` | строка пропускается | — | да, «Пустое имя варианта» |
| `# комментарий`, пустая строка | строка пропускается | — | нет |
| две одинаковые строки | два отдельных варианта | — | нет |

Правило для двоеточия в названии: если после последнего двоеточия стоит не число, двоеточие считается частью названия и вариантом становится вся строка (с предупреждением — на случай опечатки в весе). Если название само заканчивается на `:число` (как `встреча в 12:30`), число будет принято за вес; чтобы этого избежать, допишите вес явно: `встреча в 12:30 : 1`.

Файл со всеми этими случаями: `examples/input/список с ошибками.txt`, ожидаемый разбор: `examples/output_expected/parse.json`.
