# React App Launcher

Статус: `working`  
Зрелость: `M2`  
Флаги: `O, P`  
Основной интерфейс: `gui/electron`

## Что делает

Локальный React + Electron лаунчер профилей: запускает приложения, папки, файлы, сайты и команды из пользовательского списка.

## Когда использовать

Когда часто приходится открывать один и тот же набор программ/папок/ссылок для работы, учёбы, игр или другого сценария.

## Быстрый запуск

```bash
npm install
npm run dev
```

Сборка Windows portable EXE:

```bash
npm run dist:win
```

## Вход

Профили в `apps.json`. Стартовый пример лежит в `data/apps.json`, рабочая копия после запуска хранится в userData-папке Electron-приложения.

Типы элементов:

- `app` — программа;
- `folder` — папка;
- `file` — файл через приложение по умолчанию;
- `url` — сайт;
- `command` — внешний исполняемый файл или команда. Raw shell-команды требуют явного `allowShell: true` в JSON.

## Выход

GUI показывает профили, статусы путей и журнал запуска. Конфиг сохраняется в пользовательской папке приложения.

## Побочные эффекты и предупреждения

- Удаляет файлы: нет.
- Перезаписывает файлы: да, пользовательский `apps.json` при сохранении профилей.
- Использует сеть: не сам; но может открыть URL в браузере.
- Запускает внешние команды: да.
- Может содержать приватные данные: да, config хранит пользовательские пути и список привычек запуска.

Флаг `O` означает, что к профилям запуска нужно относиться как к исполняемым действиям. Тип `command` опаснее `app/folder/file/url`.

## Интерфейсы

| Слой | Статус | Комментарий |
|---|---|---|
| core | partial | логика запуска в `electron/main.cjs` |
| api | ipc | `electron/preload.cjs` |
| abi | user_config_json | `apps.json` |
| cli | npm_scripts | npm scripts |
| gui | yes | React/Electron |
| apk | no | не требуется |
| web_localhost | local_dev_only | Vite dev server только для разработки |

## Зависимости

- Node.js: `>=20` expected.
- npm packages: React, Vite, Electron, electron-builder, service packages.
- external: программы, которые пользователь сам укажет в профилях.

## Проверка

```bash
node scripts/smoke_test.js
```

Smoke-тест без `npm install` проверяет `package.json`, `data/apps.json`, Vite `base: './'` и отсутствие `latest`-зависимостей.

## Как изменить под себя

- UI: `src/App.jsx`, `src/styles.css`.
- Electron main process: `electron/main.cjs`.
- IPC contract: `electron/preload.cjs`.
- Начальный config: `data/apps.json`.

## Граница применимости

Инструмент не является sandbox. Всё, что пользователь добавил в профиль запуска, будет выполняться локальной машиной. Перед запуском чужого `apps.json` нужно просмотреть его вручную.

## Заметка по сборке

`vite.config.js` использует `base: './'`, чтобы packaged Electron не открывал пустое окно из-за абсолютных путей к ассетам.
