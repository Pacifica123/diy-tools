# StartDeck

Статус: `working`  
Зрелость: `M2`  
Флаги: `O, P`  
Основной интерфейс: `gui/electron`  
Технический ID капсулы: `react_app_launcher`

**StartDeck** — локальный React + Electron лаунчер профилей. Он запускает выбранный набор программ, папок, файлов, сайтов и команд одной кнопкой.

## Что изменилось в версии 0.3.1

- Публичное имя инструмента обновлено до `StartDeck`.
- Дефолтный `data/apps.json` теперь пустой и не содержит личных путей.
- Безопасный пример вынесен в `data/example-apps.json` и в кнопку `+ Пример`.
- Пользовательские профили хранятся в папке данных Electron-приложения, отдельно от проекта.
- Если `safeStorage` доступен, конфиг сохраняется как `profiles.encrypted.json`.
- Если шифрование недоступно, используется обычный `profiles.json`.
- Сохранена защита команд: raw shell разрешается только при `allowShell: true` в JSON.
- Зависимости закреплены конкретными версиями, без `latest`.

## Когда использовать

Когда часто приходится открывать один и тот же набор программ, папок и ссылок для работы, учёбы, игры, записи видео или диагностики ПК.

## Быстрый запуск

```bash
npm install
npm run dev
```

Сборка Windows portable EXE:

```bash
npm run dist:win
```

## Вход

Профили запуска имеют JSON-формат:

```json
{
  "profiles": [
    {
      "id": "work",
      "name": "Работа",
      "description": "Основной рабочий набор",
      "items": []
    }
  ]
}
```

Поддерживаемые типы элементов:

- `app` — программа;
- `folder` — папка;
- `file` — файл через приложение по умолчанию;
- `url` — сайт;
- `command` — внешний исполняемый файл или команда.

Raw shell-команды отключены по умолчанию. Для них нужно вручную указать `allowShell: true` в JSON. Это намеренное ограничение, потому что профиль запуска фактически является списком локальных действий.

## Конфиги и приватность

В репозитории и devctl-патче нет личных путей.

`data/apps.json` специально пустой:

```json
{
  "profiles": []
}
```

Безопасный пример лежит отдельно:

```text
data/example-apps.json
```

После первого запуска рабочие профили сохраняются в папке данных приложения, а не в `data/apps.json` внутри проекта.

Обычно это будет путь вида:

```text
C:\Users\<user>\AppData\Roaming\StartDeck\profiles.encrypted.json
```

Если системное шифрование недоступно, приложение использует:

```text
profiles.json
```

## Выход

GUI показывает профили, статусы путей, путь к текущему конфигу и журнал запуска. При запуске профиля возвращается результат по каждому элементу: успешно, пропущено или ошибка.

## Побочные эффекты и предупреждения

- Удаляет файлы: нет.
- Перезаписывает файлы: да, пользовательский конфиг профилей при сохранении.
- Использует сеть: не сам; но может открыть URL в браузере.
- Запускает внешние команды: да.
- Может содержать приватные данные: да, пользовательский конфиг хранит пути и привычки запуска.

Флаг `O` означает, что к профилям нужно относиться как к исполняемым действиям. Тип `command` опаснее `app`, `folder`, `file` и `url`.

## Интерфейсы

| Слой | Статус | Комментарий |
|---|---|---|
| core | partial | логика запуска в `electron/main.cjs` |
| api | ipc | `electron/preload.cjs` |
| abi | user_config_json | формат профилей |
| cli | npm_scripts | `npm run ...` |
| gui | yes | React/Electron |
| apk | no | не требуется |
| web_localhost | local_dev_only | Vite dev server только для разработки |

## Зависимости

- Node.js: `>=20` expected.
- npm packages: React, Vite, Electron, electron-builder и служебные пакеты из `package.json`.
- external: программы, которые пользователь сам укажет в профилях.

## Проверка

```bash
node scripts/smoke_test.js
```

Smoke-тест без `npm install` проверяет `package.json`, `data/apps.json`, `data/example-apps.json`, Vite `base: './'`, IPC-контракт, шифруемое хранилище и защиту `allowShell`.

## Как пользоваться

1. Запусти StartDeck.
2. Создай профиль, например `Работа`.
3. Нажми `+ Добавить`.
4. Выбери тип элемента: программа, папка, файл, сайт или команда.
5. Для программы, папки или файла нажми `Выбрать`, чтобы не писать путь вручную.
6. Укажи имя процесса, если нужна защита от повторного запуска.
7. Включи или отключи нужные элементы тумблером.
8. Нажми `Запустить всё`.

## Как изменить под себя

- UI: `src/App.jsx`, `src/styles.css`.
- Electron main process: `electron/main.cjs`.
- IPC contract: `electron/preload.cjs`.
- Стартовый пустой config: `data/apps.json`.
- Безопасный пример: `data/example-apps.json`.

## Граница применимости

Инструмент не является sandbox. Всё, что пользователь добавил в профиль запуска, будет выполняться локальной машиной. Перед запуском чужого JSON-профиля его нужно просмотреть вручную.
