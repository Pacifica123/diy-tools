# Внешний контракт logheaderparser

Версия контракта: 1

Контракт — это то, на что может опираться другая программа или будущий автор: способ вызова, аргументы, коды возврата и формат JSON-отчёта. Версия записана в `tool.ini` (`[data] contract_version`), в `src/main.rs` (`CONTRACT_VERSION`) и в каждом JSON-отчёте (`"contract_version": 1`).

Правило: несовместимое изменение = новая версия контракта + запись в `CHANGELOG.md`. Добавление нового необязательного аргумента или нового поля в отчёт несовместимым изменением не считается.

## Вызов

```text
cargo run -- <лог-файл> [--threshold ЧИСЛО] [--max-patterns N] [--examples N]
                        [--top N] [--json ФАЙЛ] [--progress-lines N]
```

Лаунчеры `run.sh` и `run.bat` передают аргументы как есть и не меняют текущую папку.

| Аргумент | По умолчанию | Смысл |
|---|---|---|
| `<лог-файл>` | — | Один текстовый файл. Обязателен. |
| `--threshold` | `0.62` | Доля совпавших токенов, начиная с которой строка относится к уже найденному шаблону. От 0.0 до 1.0. |
| `--max-patterns` | `20000` | Предел числа шаблонов. Строки сверх предела собираются в один шаблон `<UNCLASSIFIED_AFTER_LIMIT>`. |
| `--examples` | `3` | Сколько строк-примеров хранить на шаблон. `0` — не сохранять содержимое лога в отчёте. |
| `--top` | `50` | Сколько шаблонов показать в сводке. На JSON-отчёт не влияет. |
| `--json` | нет | Путь JSON-отчёта. Существующий файл заменяется. |
| `--progress-lines` | `1000000` | Печатать прогресс в stderr каждые N строк. `0` — не печатать. |

## Вход

- Файл читается построчно, целиком в память не загружается. Конец строки — `\n`, завершающие `\r` отбрасываются.
- Байты, которые не являются UTF-8, заменяются знаком подстановки; чтение не прерывается.
- Пустые строки считаются в `total_lines`, но в шаблоны не попадают.
- Строка делится на токены по пробельным символам. Шаблоны сравниваются только между строками с одинаковым числом токенов.

## Нормализация токенов

Сначала с краёв токена снимаются `,` `;` `"` `'`. Затем:

| Токен | Во что превращается |
|---|---|
| `ключ=значение`, где ключ состоит из латиницы, цифр, `_`, `-`, `.` и не длиннее 40 символов | `ключ=<*>`, если значение переменное; иначе `ключ=значение` в нижнем регистре |
| дата/время (`2026-06-12`, `2026-06-12T10:00:01Z`, `10:00:01,120`, `12/06/2026`, в том числе с `[` или `]` по краям) | `<TS>` |
| IPv4, в том числе с портом | `<IP>` |
| UUID | `<UUID>` |
| число, в том числе с суффиксом `ms`, `s`, `m`, `h`, `kb`, `mb`, `gb`, `%` | `<NUM>` |
| шестнадцатеричная строка от 8 знаков, в том числе с `0x` | `<HEX>` |
| `http://…`, `https://…` | `<URL>` |
| путь: есть `/` или `\`, и токен длиннее 12 байт либо содержит цифру | `<PATH>` |
| смесь латинских букв и цифр длиной 6–80 из букв, цифр и `-_:.` | `<ID>` |
| остальное | слово без скобок по краям; латиница приводится к нижнему регистру, прочие алфавиты не меняются |

Когда строка присоединяется к шаблону, различающиеся позиции заменяются на `<*>`.

## JSON-отчёт

```json
{
  "contract_version": 1,
  "file": "путь к входному файлу, как он был передан",
  "total_lines": 14,
  "total_bytes": 1320,
  "unique_patterns": 8,
  "patterns": [
    {
      "id": 0,
      "template": "<TS> info request id=<*> user=<*>",
      "count": 2,
      "first_line": 1,
      "last_line": 2,
      "examples": ["исходные строки лога, не больше --examples штук"]
    }
  ]
}
```

- `patterns` отсортирован по убыванию `count`, при равенстве — по `template` (побайтно).
- `id` — порядок появления шаблона, начиная с 0.
- `first_line` и `last_line` — номера строк с 1.
- Отчёт содержит путь к логу и, если `--examples` не 0, строки лога: это приватные данные.

Готовые примеры — в `examples/output_expected`.

## stdout и stderr

- stdout: сводка — `Готово.`, `Файл`, `Обработано строк`, `Обработано байт`, `Найдено шаблонов`, `Ошибок`, список самых частых шаблонов, последней строкой `Отчёт: …`, если указан `--json`.
- stderr: строки прогресса и сообщения об ошибках.

Для разбора программой используйте JSON-отчёт, а не stdout.

## Коды возврата

| Код | Значение |
|---|---|
| `0` | Файл обработан. |
| `1` | Ошибка: файл не открылся, отчёт не создался, недопустимое значение `--threshold` или `--max-patterns`. |
| `2` | Неверные аргументы командной строки. |

## Что не входит в контракт

- Точный текст сводки и строк прогресса.
- Какие именно строки попадут в `examples`, если их больше лимита (сейчас — первые).
- Скорость и расход памяти.
- Заголовки `Usage:` и `Options:` в `--help`: их печатает библиотека разбора аргументов, они остаются английскими.
