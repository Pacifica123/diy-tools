# CHANGELOG

## 0.1.3

- Исправлен parser-баг: bare-ссылка на уже объявленный внешний узел изнутри `subgraph` больше не переносит этот узел внутрь группы.
- Layout теперь не даёт top-level `subgraph` рамкам визуально накладываться друг на друга.
- Слишком широкие слои переносятся в несколько строк/колонок, чтобы fan-out меньше раздувал canvas по ширине.
- Обратные и встречные рёбра выбирают ближайшую сторону узла, а не всегда уходят через длинную боковую магистраль.
- Smoke-тест расширен проверкой внешних ссылок из subgraph, переноса fan-out и отсутствия наложения top-level групп.

## 0.1.2

- Исправлена SVG-тема: белый canvas, более контрастные группы, узлы, рёбра и подписи рёбер.
- Кривые рёбра заменены на ортогональные ломаные линии, которые проще читать в архитектурных схемах.
- Добавлена простая barycentric-сортировка узлов внутри слоёв для уменьшения пересечений.
- Рендер теперь явно разделяет слои: фон, группы, рёбра, подписи рёбер, узлы, текст узлов.
- Fan-out из одного узла теперь использует разные порты выхода/входа, чтобы стрелки не выходили одной неразборчивой пачкой.
- Улучшена обработка стрелок к subgraph/group как к рамке группы.
- Smoke-тест проверяет ортогональные рёбра, порядок SVG-слоёв и fan-out spacing.

## 0.1.1

- Исправлена раскладка циклических графов: canvas больше не раздувается из-за обратных стрелок.
- Добавлено переносимое разбиение длинных подписей узлов на строки.
- GUI больше не сжимает крупную SVG-схему в один виджет: добавлены прокрутка и масштаб `-`, `+`, `100%`, `По ширине`.
- Стрелки к `subgraph` по id теперь могут попадать в рамку группы без создания лишнего одноимённого узла.
- Smoke-тест расширен проверкой цикла и ссылки на группу.

## 0.1.0

- Добавлена первая капсула `mpl`.
- Реализованы слои `core`, `api`, `abi`, `cli`, `gui`.
- Поддержан Mermaid-subset для `flowchart`/`graph`, направлений, узлов, стрелок, подписей и `subgraph`.
- Добавлен SVG-renderer и Qt GUI-превью.
