# CHANGELOG

## 0.2.0

Доведение капсулы до M3 (Stable Utility). Версия внешнего контракта: 1 (ABI `mpl-json 0.1`).

Исправлено:

- Цепочки рёбер `A --> B --> C` (в том числе с подписями и разными видами стрелок) раньше молча читались как одно ребро `A → C` с подписью `> B`, а средний узел терялся. Теперь цепочка даёт все узлы и по ребру на каждое звено. Стрелки внутри скобок и кавычек (`A[x --> y]`) по-прежнему считаются текстом подписи.
- `---` перед более поздней стрелкой в той же строке больше не превращается в подпись.
- Эталон `examples/output_expected/basic_flow.svg` был от версии 0.1.0 и не совпадал с реальным выводом; эталоны пересозданы настоящим CLI.
- `run.sh`/`run.bat` больше не делают `cd` в папку капсулы: относительные пути в `--input/--svg/--ast` считаются от папки пользователя. `run.sh` зовёт `python3` и по-русски сообщает, если его нет.
- `__version__` в коде отставал (`0.1.0`); теперь совпадает с `tool.ini`.
- `--abi-json` с JSON-массивом вместо объекта давал код 3 и английское сообщение; теперь это ошибка входа (код 2).

Добавлено:

- `"contract_version": 1` во всём JSON, который выдаёт инструмент (результат `--json`/`--abi-json` и файл `--ast`); результат `--json` теперь содержит и блок `abi`, как `--abi-json`.
- JSON ошибки в режиме `--abi-json`: `{"ok": false, "error": {"code", "kind", "message"}, ...}` в stdout; коды возврата прежние.
- Итоговый отчёт CLI при записи файлов (`Готово.`, счётчики, предупреждения, `Результат:`, `Отчёт:`); при одновременном `--json` отчёт идёт в stderr, чтобы stdout оставался чистым JSON.
- stdin/stdout CLI принудительно в UTF-8, независимо от локали и ОС.
- `docs/CONTRACT.md` (указатель) и расширенный `docs/ABI.md`: аргументы, поля AST, файлы, stdout/stderr, коды возврата, граница контракта.
- Регрессионные примеры: обратные связи и кластер, веер с переносом слоя, внешний узел из subgraph, все формы узлов и виды стрелок, вход с предупреждениями и эталон ошибки `--strict`. Для каждого входа есть эталонные AST JSON и SVG.
- Smoke сравнивает AST и SVG целиком для всех примеров, проверяет ошибки и коды возврата, запуск из другой папки с пробелами и кириллицей в путях и поведение без PySide6. GUI smoke не проверяет.

## 0.1.4

- Top-level `subgraph` теперь раскладываются как отдельные compact-cluster блоки, а не смешиваются с обычными узлами в общей сетке рангов.
- Внутренние узлы группы получают локальную раскладку внутри рамки группы; внешние узлы больше не оказываются визуально под чужой group-рамкой.
- Для ранжирования верхнего уровня обратные ссылки в сторону уже объявленных узлов считаются back-link, а не причиной переставлять старые блоки.
- Обратные рёбра больше не уходят через дальние side-lane линии над схемой или сбоку от неё; вместо этого используется компактная ортогональная dogleg-линия.
- Smoke-тест расширен проверкой, что top-level group не накрывает внешние узлы и что back-edge routing остаётся локальным.

## 0.1.3

- Исправлен parser-баг: bare-ссылка на уже объявленный внешний узел изнутри `subgraph` больше не переносит этот узел внутрь группы.
- Layout теперь не даёт top-level `subgraph` рамкам визуально накладываться друг на друга.
- Слишком широкие слои переносятся в несколько строк/колонок, чтобы fan-out меньше раздувал canvas по ширине.
- Обратные и встречные рёбра выбирают ближайшую сторону узла, а не всегда уходят через длинную боковую магистраль.
- Smoke-тест расширен проверкой внешних ссылок из subgraph, переноса fan-out и отсутствия наложения top-level групп.

## 0.1.2

- Исправлена SVG-тема: белый canvas, более контрастные группы, узлы, рёбра и подписи рёбер.
- Кривые рёбра заменены на ортогональные ломаные линии, которые проще читать в архитектурных схемах.
- Добавлена простая barycentric-сортировка узлов внутри слоёв для уменьшения пересечений.
- Рендер теперь явно разделяет слои: фон, группы, рёбра, подписи рёбер, узлы, текст узлов.
- Fan-out из одного узла теперь использует разные порты выхода/входа, чтобы стрелки не выходили одной неразборчивой пачкой.
- Улучшена обработка стрелок к subgraph/group как к рамке группы.
- Smoke-тест проверяет ортогональные рёбра, порядок SVG-слоёв и fan-out spacing.

## 0.1.1

- Добавлено переносимое разбиение длинных подписей узлов на строки.
- GUI больше не сжимает крупную SVG-схему в один виджет: добавлены прокрутка и масштаб `-`, `+`, `100%`, `По ширине`.

- Smoke-тест расширен проверкой цикла и ссылки на группу.
