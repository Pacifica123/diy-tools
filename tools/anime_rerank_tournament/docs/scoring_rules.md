# Правила оценивания

Новая оценка зависит только от места в итоговом рейтинге и размера списка `N`. Все правила ниже проверяются smoke-тестом для каждого `N` от 1 до 1300; готовые распределения для характерных размеров записаны в `examples/output_expected/scoring_distributions.json`.

## Как строится рейтинг

Турнир — на выбывание, поэтому точно известен только победитель. Остальные места — эвристика, по порядку признаков:

1. победитель турнира — первое место;
2. кто выбыл позже, тот выше;
3. среди выбывших в одном раунде выше тот, кто проиграл более сильному сопернику (сила соперника — его место в предварительном порядке по тем же признакам без этого пункта);
4. больше побед — выше;
5. выше старая оценка — выше (записи без оценки считаются как 0);
6. раньше во входном файле — выше.

Мест без пропусков и без делёжа; для каждого выбывшего в экспорте указано, в каком раунде и кому он проиграл.

## Лайтовый режим

Рейтинг идёт от лучшего к худшему.

- топ 1% получает 10;
- топ 10%, кроме предыдущих, получает 9;
- топ 20%, кроме предыдущих, получает 8;
- следующие 20% получают 7;
- остаток делится между 6 и 5 пополам; при нечётном остатке лишний тайтл получает 6.

Округление — `round_half_up`: 0.5 округляется вверх. Границы зон считаются от всего списка: `round(N × 0.01)`, `round(N × 0.10)`, `round(N × 0.20)`, `round(N × 0.40)`.

На коротких списках верхние оценки могут отсутствовать: оценка 10 появляется только при `N ≥ 50`, оценка 9 — при `N ≥ 5`. Например, при `N = 9` получается 9, 8, 7, 7, 6, 6, 6, 5, 5.

## Хардовый режим

В хардовом режиме оценка 10 не используется.

Сначала назначается нижняя часть:

- последние 10 — оценка 1;
- следующий 1% снизу — оценка 2;
- следующие 5% снизу — оценка 3;
- остальная нижняя половина — оценка 4.

Проценты считаются от всего списка с округлением `round_half_up`. Нижняя половина — места после `ceil(N / 2)`; оценки 2, 3 и 4 за её пределы не выходят.

Затем верхняя половина:

- слабая часть верхней половины — 5;
- средняя верхняя зона — 6;
- элитное ядро — 7/8/9 по размеру списка.

Верхняя половина — первые `ceil(N / 2)` мест. Её нижняя часть (половина с округлением вниз) получает 5, остальные — 6.

Элитное ядро — первые `max(10, round(N × 0.01))` мест, но не больше верхней половины. Оценки элитного ядра назначаются последними и имеют приоритет над всеми остальными зонами.

Следствия для коротких списков (так задумано: на маленьком списке часть оценок отсутствует):

- при `N < 20` «последние 10» заходят в верхнюю половину, но элитное ядро важнее: оценку 1 получают только места ниже верхней половины. Например, при `N = 9` получается 8, 7, 7, 7, 7, 1, 1, 1, 1;
- при `N ≤ 20` оценок 2–5 нет совсем; оценка 2 появляется при `N ≥ 50`.

### N ≤ 100

- 1 место — 8;
- 2–5 места — 7;
- остальные в элитном ядре — 6.

### 101 ≤ N ≤ 1000

- 1 место — 9;
- 2–3 места — 8;
- 4–5 места — 7;
- остальные в элитном ядре — 6.

### N ≥ 1001

- топ-3 — 9;
- места 4–10 — 8;
- остальная часть топ-1% — 7;
- если топ-1% округлился до 10, 10-е место получает 7, чтобы оценка 7 существовала.
