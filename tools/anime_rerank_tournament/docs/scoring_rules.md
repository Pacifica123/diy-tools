# Правила оценивания

## Лайтовый режим

Рейтинг идёт от лучшего к худшему.

- топ 1% получает 10;
- топ 10%, кроме предыдущих, получает 9;
- топ 20%, кроме предыдущих, получает 8;
- следующие 20% получают 7;
- остаток делится между 6 и 5.

Округление — `round_half_up`: 0.5 округляется вверх.

## Хардовый режим

В хардовом режиме оценка 10 не используется.

Сначала назначается нижняя часть:

- последние 10 — оценка 1;
- следующий 1% снизу — оценка 2;
- следующие 5% снизу — оценка 3;
- остальная нижняя половина — оценка 4.

Затем верхняя половина:

- слабая часть верхней половины — 5;
- средняя верхняя зона — 6;
- элитное ядро — 7/8/9 по размеру списка.

### N ≤ 100

- 1 место — 8;
- 2–5 места — 7;
- остальные в элитном ядре — 6.

### 101 ≤ N ≤ 1000

- 1 место — 9;
- 2–3 места — 8;
- 4–5 места — 7;
- остальные в элитном ядре — 6.

### N ≥ 1001

- топ-3 — 9;
- места 4–10 — 8;
- остальная часть топ-1% — 7;
- если топ-1% округлился до 10, 10-е место получает 7, чтобы оценка 7 существовала.
