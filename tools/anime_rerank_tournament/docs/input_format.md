# Формат входного файла

Парсер рассчитан на текстовый файл со структурой:

```text
#	Название	Оценка	Эпизоды	Тип
1	Название тайтла
	10	12/12	Сериал
2	Название другого тайтла
Комментарий пользователя
	8	1/1	Фильм
```

## Правила

- строка `# Название Оценка Эпизоды Тип` игнорируется;
- строка статистики вида `Сериалы: ... Фильмы: ...` игнорируется;
- новая запись начинается со строки `<номер> <название>`;
- строка деталей содержит `<оценка> <эпизоды> <тип>`;
- дополнительные строки между названием и деталями сохраняются как комментарий;
- кодировки: UTF-8, UTF-8 BOM, CP1251 fallback.
