# Anime Rerank Tournament

Статус: `working`  
Зрелость: `M2`  
Флаги: `I`  
Основной интерфейс: `gui`

## Что делает

Десктопная программа для турнирной переоценки списка аниме-тайтлов. Пользователь сравнивает пары, инструмент ведёт турнир, строит итоговый рейтинг и экспортирует новые оценки.

## Когда использовать

Когда старый список оценок нужно пересобрать через ручные попарные сравнения, а результат должен быть объяснимым: с историей матчей, scoring rules, undo и autosave.

## Быстрый запуск

Windows:

```powershell
run.bat
```

Linux:

```bash
sh run.sh
```

Напрямую:

```bash
python main.py
```

Перед первым GUI-запуском:

```bash
python -m pip install -r requirements.txt
```

## Вход

TXT-файл списка тайтлов. Пример: `examples/sample_input.txt`. Формат описан в `docs/input_format.md`.

Базовая форма записи:

```text
1	Название
	10	12/12	Сериал
```

## Выход

Итоговый рейтинг, новые оценки, JSON/CSV/TXT export и JSON-история матчей. Autosave сохраняет прогресс после выбора.

## Побочные эффекты и предупреждения

- Удаляет файлы: нет.
- Перезаписывает файлы: может перезаписать autosave/export по выбору пользователя.
- Использует сеть: нет.
- Запускает внешние команды: нет.
- Может содержать приватные данные: возможно, если пользовательский список приватен.

## Интерфейсы

| Слой | Статус | Комментарий |
|---|---|---|
| core | yes | `app/domain/*` |
| api | internal | parser/ranking/scoring импортируются smoke-тестом |
| abi | simple_files | TXT input, TXT/CSV/JSON export |
| cli | no | GUI-инструмент; smoke-тест отдельно |
| gui | yes | PySide6 |
| apk | no | не заявлен |
| web_localhost | no | не требуется |

## Зависимости

- Python: `>=3.11`
- pip: `PySide6>=6.6`
- external: `none`

## Проверка

```bash
python scripts/smoke_test.py
```

Smoke-тест проверяет парсер, турнирный движок, ranking и light/hard scoring на sample input.

## Как изменить под себя

- Parser: `app/domain/parser.py`.
- Турнир: `app/domain/tournament.py`.
- Scoring: `app/domain/scoring*.py` и `docs/scoring_rules.md`.
- UI: `app/ui/`.

## Граница применимости

Рейтинг является эвристикой по ручным выборам пользователя. Инструмент не доказывает объективное качество тайтлов и не должен использоваться как автоматический скорер без ручной проверки.
