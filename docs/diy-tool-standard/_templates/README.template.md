# Название инструмента

Статус: `draft`  
Зрелость: `M1`  
Флаги: `none`  
Основной интерфейс: `cli`

## Что делает

Одна-две фразы обычным языком.

## Когда использовать

- Сценарий 1.
- Сценарий 2.

## Быстрый запуск

Windows:

```powershell
run.bat
```

Linux:

```bash
./run.sh
```

CLI напрямую:

```bash
python src/cli.py --help
```

## Вход

Что нужно подать на вход: файлы, папки, текст, конфиг, действия пользователя.

## Выход

Что создаётся, изменяется или показывается.

## Побочные эффекты и предупреждения

- Удаляет ли файлы: нет/да.
- Перезаписывает ли файлы: нет/да.
- Использует ли сеть: нет/да.
- Запускает ли внешние команды: нет/да.
- Может ли report содержать приватные данные: нет/да/возможно.

## Интерфейсы

| Слой | Статус | Комментарий |
|---|---|---|
| core | planned | Где будет доменная логика |
| api | no | Почему не нужен |
| abi | simple_files | Вход/выход через файлы |
| cli | yes | Основной интерфейс |
| gui | no | Можно добавить позже |
| apk | no | Нет телефонного сценария |
| web_localhost | no | Не требуется |

## Как изменить под себя

- Доменная логика: `src/core.py`.
- CLI-аргументы: `src/cli.py`.
- Настройки по умолчанию: `config.ini`.
