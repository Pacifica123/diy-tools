# Vibe Coding Prompt Template — DIY Tool Standard v0.1-devctl

Сделай DIY-инструмент по стандарту `DIY Tool Standard v0.1-devctl`.

Главное:

- это не закрытый продукт, а капсула, которую можно понять, запустить, изменить, встроить или переписать;
- не раздувай архитектуру без причины;
- сначала реши микропроблему, потом оформляй;
- язык по умолчанию: Python, если нет причины выбрать другой;
- сеть не использовать без явного требования;
- пользовательская поверхность на русском;
- машинные ключи и имена файлов — стабильные, лучше ASCII;
- не использовать абсолютные личные пути;
- поддержать пути с пробелами и кириллицей;
- после работы вывести финальный отчёт;
- если действие опасное, включить флаг `D`, `dangerous = true`, warning, dry-run/backup/report;
- если инструмент запускает внешние команды, включить `O` и сделать журнал;
- если результат generated/best-effort, включить `G` и audit output;
- если инструмент интерактивный, включить `I`, autosave, undo/history/export;
- если инструмент потоково читает большие файлы, включить `S`, progress и лимиты памяти;
- сделать `README.md`, `tool.ini`, launcher-и, examples и минимальную проверку по выбранной зрелости;
- подготовить результат как devctl-патч: `manifest.json`, `files/`, `PATCH_SUMMARY.md`.
