# Acceptance Checklist

## Для любого M1+ инструмента

- [ ] Есть `README.md` на русском.
- [ ] Есть `tool.ini`.
- [ ] Назван статус: `draft/working/tested/stable/broken/deprecated`.
- [ ] Указаны зрелость и флаги.
- [ ] Описаны вход и выход.
- [ ] Описаны побочные эффекты.
- [ ] Указано, использует ли сеть.
- [ ] Указано, удаляет/перезаписывает ли файлы.
- [ ] Указаны зависимости.
- [ ] Есть понятный запуск.
- [ ] Нет абсолютных личных путей.
- [ ] Есть минимальный пример или проверка.
- [ ] После выполнения есть финальный отчёт.
- [ ] Инструмент можно скопировать как капсулу или честно сказано, почему пока нельзя.

## Дополнительно для M3

- [ ] `CHANGELOG.md`, новая версия сверху.
- [ ] `docs/CONTRACT.md` с версией контракта; та же версия в `tool.ini` и в JSON, который пишет инструмент.
- [ ] `examples/input` и `examples/output_expected`; эталоны получены настоящим запуском.
- [ ] Smoke сравнивает результат с эталоном целиком и падает при расхождении (проверено намеренной поломкой).
- [ ] Smoke пишет только во временный каталог, работает из любой папки, не требует сети и GUI-библиотек.
- [ ] `tested` стоит только у того, что действительно запускалось; `tested_scope` называет непроверенное.
- [ ] Лаунчер CLI-инструмента не меняет текущую папку.
- [ ] Строка в `TOOLS.md` совпадает с `tool.ini`.

## Дополнительно для D

- [ ] `dangerous = true`.
- [ ] Есть warning.
- [ ] Есть dry-run, backup, recycle или отчёт изменений.
- [ ] Тест проводился на копии данных.

## Дополнительно для S

- [ ] Нет загрузки всего файла в память без причины.
- [ ] Есть progress.
- [ ] Есть лимиты памяти/шаблонов/примеров.
- [ ] Report не раскрывает приватные данные без маркировки.

## Дополнительно для G

- [ ] Generated output помечен как best-effort.
- [ ] Есть audit output.
- [ ] README требует ручной проверки перед применением.

## Дополнительно для I

- [ ] Есть autosave.
- [ ] Есть undo/history или объяснение, почему не нужно.
- [ ] Правила scoring/randomness описаны.
- [ ] Есть export.

## Дополнительно для O

- [ ] Команды/пути проверяются перед запуском.
- [ ] Тип `command` отделён от app/folder/file/url.
- [ ] Есть журнал запуска и ошибок.
- [ ] Нет небезопасной склейки shell-команд из пользовательского ввода.
