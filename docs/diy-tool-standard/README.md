# DIY Tool Standard v0.1-devctl

Статус: первая прикладная версия стандарта разработки маленьких личных и полуличных инструментов.

Этот каталог добавлен devctl-патчем. Он предназначен не как «ещё одна документация», а как стартовая методология для будущего зоопарка инструментов: скриптов, CLI, GUI, Electron/desktop-утилит, Rust/Go-бинарников, APK-оболочек и будущего менеджера инструментов.

## Что читать

1. `STANDARD.md` — канонический стандарт.
2. `DEVCTL_PATCH_PROTOCOL.md` — как оформлять будущие изменения и новые инструменты через `devctl`.
3. `SOURCE_TOOL_AUDIT.md` — какие требования добавлены после разбора уже существующих инструментов.
4. `_templates/` — шаблоны README, `tool.ini`, реестра, prompt-а и patch summary.
5. `standard_manifest.json` — машинно-читаемая карточка версии стандарта.

## Короткая формула

```text
Микропроблема → капсула инструмента → явный контракт → честный риск → минимальная проверка → devctl-патч → след в реестре.
```

Главная защита стандарта: он не должен становиться тяжелее самой микропроблемы. Уровни зрелости и флаги риска существуют именно для того, чтобы одноразовый скрипт не оформлялся как платформа, а опасный инструмент не маскировался под безобидную кнопку.
